# Jev 화면 정보 최소화

2026-11-05. 휴대폰의 `AgentTurnGateway`는 HTTP 호출 직전에 `SettingsScreenPrivacy`를 적용한다. 공유 `vision_vocabulary.json`의 정확한 메뉴 이름만 허용하며, 제조사 문구를 추가하려면 이 목록을 명시적으로 수정하고 검증한다. 알 수 없는 문구를 원문으로 보내는 예외는 없다. 로컬 화면 비교·화면 조작용 스냅샷은 기기 안에서 유지한다.

설정 패키지와 검토된 런처만 허용한다. 런처에서는 설정 아이콘 이름만 남긴다. 계정 이름·이메일·알림 내용·입력 내용·메뉴의 부가 설명을 제거하고 메뉴 제목·계층·역할·조절값·기기 안에서 조작에 필요한 좌표를 백엔드에 보낸다. 입력 화면, 계정·인증·알림 기록 화면 및 허용 메뉴를 확인할 수 없는 화면은 전송을 중단하고 직접 진행하도록 안내한다. 빈 네이티브 트리는 기존의 동의 기반 기기 OCR 경로에서만 추가 근거를 얻을 수 있으며 자체로 Jev 호출을 만들지 않는다. 정책 로드 실패도 전송을 차단한다.

백엔드의 Jev runtime은 원래 노드에서 민감 화면 여부를 다시 검사하고, 활성 graph의 setting에 해당하는 허용 메뉴만 남긴 뒤 정규화한다. `JevScreenResolver`가 외부 호출 직전 다시 허용 목록을 적용한다. 글자 크기 작업이면 설정·디스플레이·접근성·글자 크기 등의 승인된 경로 제목과 슬라이더 관계만 전송한다. 주변 설명·원래 노드 ID·패키지·좌표·사용자 원문·검증 설명·이벤트 ID·전체 graph 직렬화는 전송하지 않는다. graph는 단계 ID·제목·연결·조작 역할·우선순위로 축소하며, 이전 조작은 graph의 transition ID·유한한 기준값·이벤트 수신 여부만 남긴다.

민감 화면 차단은 Jev가 선택하지 못한 경우의 재관찰과 구별한다. 화면 전송과 자동 안내를 중단하고 사용자가 직접 진행하도록 안내하며, 불명확한 화면에 임의의 좌표를 만들지 않는다. 앱의 차단은 해당 요청을 일시 중지하므로 지원 화면으로 돌아온 뒤 다시 요청해야 한다.

기존 세션·학습 기록 정책은 유지한다. 원문 화면·전체 Tree·OCR·이미지를 DB에 저장하지 않고 단계·성공 여부·숫자형 지연·상태 코드만 기록한다. `conversation_storage`와 `model_training` 동의 및 철회 처리는 별개이며, Jev 사용이나 ZDR이 학습 동의를 대신하지 않는다. 해시·세션 식별자는 익명화 보장이 아니며 기존 보존·삭제 정책을 따른다. 기존 파일·로그를 자동 삭제하거나 과거 저장분을 소급 정리하지 않는다.

화면 선택 진단에는 `filter_time_ms`, `payload_bytes`, `exported_node_count`, `provider_latency_ms`를 허용한다. 입력·출력 본문이나 예외 원문은 추가하지 않는다. 필터는 집합 조회와 필드 선택만 수행하고 별도 모델을 호출하지 않는다. 합성 회귀 테스트로 메뉴 선택·기하 검증·승인·완료 조건을 확인한다. 실제 삼성/기타 제조사 기기에서 메뉴 선택 정답률, 작업 성공률, 오차단율, 지연 p50/p95를 같은 graph/model로 전후 비교해야 하며 단위 테스트나 가짜 HTTP 응답을 실제 Jev 품질로 보고하지 않는다.

TypeSafe 계정의 ZDR은 [연결 및 ZDR 절차](../inference/jev.md)를 따른다. 활성화 확인은 아직 남아 있다. 계정 설정과 전송 전 필터는 독립적으로 필요하다.
