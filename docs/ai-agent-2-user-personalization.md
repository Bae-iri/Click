# AI-Agent(2): 사용자별 맞춤 안내

AI2의 사용자 분석 모듈 `ai_agent.user_modeling`은 사용자별·등록 화면별 어려움 이력을 분석한다. 기존 graph proposal 작업과 별개이며, 현재는 규칙 기반 분석이고 LLM 학습은 하지 않는다.

동의가 있는 UI 이벤트를 저장하면서 `user_ui_profiles.state_difficulties`에 어려움 횟수, 완료 횟수, 연속 어려움 횟수와 마지막 이벤트를 함께 저장한다. 실패·도움 요청·반복 안내·혼란 이벤트가 같은 화면에서 연속 두 번 발생하면 해당 화면의 안내를 구체화한다. 완료 이벤트는 연속 횟수를 초기화한다. 나이, 직업, 탭 소요 시간만으로 어려움을 추정하지 않는다.

Android의 “다시 말해줘” 요청은 현재 안내 화면의 `guide_repeated` 이벤트를 전송한다. 실패·도움·혼란·완료는 기존 이벤트 API로 접수할 수 있으며, 런타임 검증 결과의 자동 수집은 아직 연결하지 않았다. 동의를 철회하면 원본 이벤트와 파생 이력을 삭제하고 재시도 응답에도 맞춤 정보를 제공하지 않는다.

배포 전에 Backend에서 `alembic upgrade head`로 스키마를 적용한다. Android 실기기 검증은 별도로 필요하다. 이벤트 전송은 best effort이며 오프라인 재전송·중복 제거는 후속 작업이다. 현재 키는 등록 화면 ID이므로 화면 ID를 공유하는 다른 task를 추가할 때 task별 키로 확장해야 한다.
