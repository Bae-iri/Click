# 사용자에게 맞는 안내 표현

현재 맞춤 안내는 Android의 계정별 기기 저장소에서 처리한다. 예전에 사용하던 서버 사용자 프로필·이벤트 개인화 API는 종료되었으며 `410`을 반환한다. AI2의 성공 경로 분석·재사용은 이 안내 표현 맞춤과 별개다.

- 기본은 기억하지 않기다. 안내의 ‘이유·다시 확인 → 안내 평가·방식 바꾸기’에서 읽기 속도와 설명 방식을 선택한다. 기억하지 않으면 이번 작업에만 적용한다.
- ‘다음 안내에도 기억하기’를 켜면 선택한 느린 읽기·자세한 설명·간단한 설명을 다음 작업에도 반영한다. 기억하기가 켜진 상태에서 같은 작업의 설명을 두 번 다시 요청하면 자세한 설명을 기억하고 그 변경을 알린다.
- 음성 속도는 해당 안내 재생에 적용한다. 다른 튜토리얼의 재생 속도를 바꾸지 않는다. 간단한 설명에서도 실제 조작 지시·위험 안내는 제거하지 않는다.
- 위치 오류 피드백은 이번 작업의 자동 진행을 멈춘다. 사용자가 다시 확인을 선택하면 현재 화면을 새로 읽으며, 이 피드백만으로 자동 조작 권한이나 전역 자동 모드를 변경하지 않는다.
- 이 기능은 요청·화면 원문·나이·직업·능력 추정을 저장하거나 서버로 보내지 않는다. 계정별 선택과 고정된 피드백 종류만 기기에 보관한다.
- ‘설정 → 안내 방식’에서 기억하기를 끄거나 기억한 선택을 지울 수 있다. 다음 작업은 기본 안내로 돌아간다. 작업 중에 적용한 일회성 선택은 해당 작업이 끝날 때 초기화한다.

별도의 ‘피드백 보내기’는 개발팀의 개선 검토를 위한 서버 저장이다. 개별 의견 전송으로 현재 설정이나 다음 안내 방식이 자동 변경되지 않는다는 설명을 입력창에 표시한다.
