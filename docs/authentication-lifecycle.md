# 로그인과 계정 수명주기

클릭 1.0.5는 로그인한 세션을 기준으로 작업 요청과 계정 관리를 처리한다.

- 전화번호 가입·로그인과 카카오 로그인 성공 시 사용자, 액세스 토큰, 갱신 토큰, 만료 시각을 검증한 뒤 암호화 저장소에 동기 저장한다. 새 로그인에는 별도의 세대 식별자를 부여한다.
- 작업 요청의 토큰이 만료되면 갱신하고 한 번 재시도한다. 다른 요청이 이미 갱신한 토큰은 다시 회전시키지 않는다.
- 이전 세션의 갱신 응답은 새 로그인 정보를 삭제하거나 덮어쓰지 않는다. 이전 계정의 요청을 새 계정의 인증 정보로 재전송하지 않는다.
- 로그아웃·탈퇴는 시작 당시의 사용자와 로그인 세대에 묶인다. 처리 중 새로 로그인하면 새 세션을 지우거나 그 토큰으로 계정 관리 요청을 보내지 않는다.
- 일시적인 통신 오류, 429, 5xx는 로그인을 지우지 않는다. 현재 세션의 갱신 토큰을 서버가 명시적으로 거절한 경우만 인증 정보를 지운다.

## 카카오로 시작하기

카카오 SDK를 호출하기 전에, 클릭 계정이 없으면 새 계정이 생성된다는 확인을 받는다. 확인창을 취소하면 SDK 인증과 클릭 서버의 로그인·가입 요청 모두 시작하지 않는다. 카카오톡 자체의 로그인 상태와 클릭 계정은 별개이며, 카카오 인증이 비밀번호 입력 없이 끝날 수 있다.

서버의 기존 카카오 인증 규격을 유지하므로 기존 운영 서버와 호환된다. 확인 절차는 앱 진입 흐름에 적용된다.

## 회원 탈퇴

먼저 클릭 서버의 계정 삭제 성공을 확인한 뒤 로컬 인증·자동 조작 상태를 지운다. 카카오 계정이면 카카오 SDK 연결 해제를 요청한다. 이전 앱의 계정은 당시 카카오 로그인 시 전화번호 프로필을 제거했던 동작을 기준으로 구분한다.

카카오 연결 해제 실패나 15초 시간 초과를 연결 해제 성공으로 표시하지 않는다. 클릭 계정 삭제는 완료됐지만 외부 연결 해제는 미완료임을 별도로 알리고, 다음 카카오 진입 확인창에도 안내한다. 일반 로그아웃에서는 카카오 연결 해제를 요청하지 않는다.

## 검증

- Android 단위 검사는 로그인 화면, 가입 입력 규격, 취소, 동시 요청, 지연된 401·갱신·로그아웃 응답, 계정 변경, 탈퇴 실패와 연결 해제 실패를 검사한다.
- `AuthSessionDeviceRegressionTest`는 별도 테스트 앱과 `http://127.0.0.1:18780`의 일회용 서버에서만 실행한다. 실제 기기의 암호화 저장소와 HTTP 경계를 사용해 카카오 인증 응답 저장·즉시 작업·갱신·재로그인, 전화번호 가입·로그인·잘못된 비밀번호·중복 가입·즉시 작업을 검사한다.
- 실기기 회귀의 카카오 제공자 검증 응답은 합성이다. 실제 카카오 SSO나 운영 사용자 계정의 삭제·연결 해제를 검증했다고 주장하지 않는다.
- Release APK는 기존 업로드 키로 서명해야 설치된 앱을 데이터 유지 방식으로 업데이트할 수 있다. 서명 전 APK는 설치용 완료본이 아니다.
