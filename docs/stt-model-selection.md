# 음성 입력

메인 오버레이의 `DeviceSpeechInput`은 Android 12(API 31) 이상에서 `isOnDeviceRecognitionAvailable()`을 확인하고 `createOnDeviceSpeechRecognizer()`로 기기 내 음성 인식만 사용한다. 한국어(`ko-KR`)와 중간 인식 결과를 요청하고 마이크 버튼을 놓으면 `stopListening()`으로 결과를 확정한다.

취소·화면 이탈·시간 초과 시 인식기를 해제하고 늦은 콜백은 무시한다. 지원 불가·한국어 모델 미준비·인식 오류 시 글 입력을 안내하며 모델 다운로드를 자동 요청하지 않는다.

Backend에는 인식된 텍스트만 보내 목표 확인과 작업 대기열에 사용한다. 서버 음성 업로드 API와 별도 음성 추론 프로세스는 제공하지 않는다.

튜토리얼은 실제 녹음이나 마이크 권한 요청 없이 고정 예시로 조작만 연습한다. 입력창을 열거나 TTS가 끝나는 것만으로 녹음하지 않는다.

실제 한국어 인식 품질과 기기별 종료 동작은 실기기에서 검증한다. [평가 기준](ai-quality-evaluation.md)을 따른다.
