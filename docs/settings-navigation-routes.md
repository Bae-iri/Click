# Android 설정 화면 안내 경로

2026-11-07. Catalog 2.2.0은 기존 160개 요청에 설정 화면 열기 21개를 추가한다.
기존 89개 설정 변경 요청과 별도의 `settings.navigation.*` 계약이다.
화면 열기 경로가 추가됐다는 이유로 와이파이 연결·스위치 변경·초기화 같은 기존 변경 작업을 승인하지 않는다.

## 실행 범위

- 기본: 설정, 디스플레이, 소리 및 진동, 연결, 접근성
- 연결: 와이파이, 블루투스
- 화면: 글자 크기, 화면 자동 꺼짐 시간, 화면 크기, 편안하게 화면 보기
- 소리: 음량, 벨소리, 알림 소리, 방해 금지
- 접근성: 시인성 향상, 청각 보조, 입력 및 동작, TalkBack, 확대, 자막

예: `와이파이 설정 열어줘`, `글자 크기 설정 열어줘`, `청각 보조 설정 열어줘`.
`와이파이 켜줘`는 별도의 변경 요청이며 화면 열기로 바꾸어 실행하지 않는다.

## 구현과 검증 경계

Backend의 `navigation_pages.json`은 정적인 화면 제목과 Samsung/AOSP의 대체 분류·중간 메뉴를 정의한다.
`settings_navigation.py`가 읽기 전용 Task Graph를 생성한다. 사용자가 메뉴를 누르며 이동하고,
보이지 않는 메뉴는 기존의 스크롤·복구 안내를 이용한다. 자동 탭이나 설정값 변경은 하지 않는다.

완료는 네이티브 Settings 패키지에서 독립된 화면 제목이 목적지와 정확히 일치할 때만 판정한다.
메뉴 행, 설명, OCR 추정, 민감 입력 화면은 완료 근거로 쓰지 않는다.
기술 결과는 `OPENED`이며 `CHANGED`와 구분한다. 이미 해당 화면에 있으면 새 조작 없이 도착을 확인할 수 있다.
Jev가 선택하는 경우에도 모델 판단을 화면 도착의 증거로 사용하지 않는다.

기존 6개 값 변경 그래프, 와이파이 켜기·끄기 2개와 신규 21개 화면 열기 그래프를 합쳐 실행 가능 그래프는 29개다. 와이파이 상태 변경은 [별도 실행 계약](tasks/wifi.md)을 따른다.
신규 경로는 합성 HTTP/런타임/Android 회귀로 검사했다. 제조사·버전별 실제 메뉴 위치,
스크롤과 실제 Jev 선택 품질은 실기기 검증 대상이며 이 문서는 이를 통과했다고 주장하지 않는다.

새로운 Android 자격 증명·개인정보 전송 권한은 추가하지 않는다.
전송 허용 목록에는 정적인 설정 메뉴 이름만 추가하고 SSID·연결 기기 이름·계정·자막 내용은 넣지 않는다.
입력·비밀번호·계정 화면 차단 정책은 유지한다.

## 반영

Backend와 APK를 함께 갱신해야 Catalog 2.2.0의 요청을 실행할 수 있다.
Backend는 기존 graph seed 과정에서 신규 불변 NAV 그래프를 등록한다.
기존 6개 변경 그래프의 버전·본문·고정 세션을 변경하지 않는다.
운영 배포와 사용자 기기 설치는 별도로 수행한다.


설정 변경 89개 전체의 최신 구분은 [설정 실행 안내](settings-execution-routes.md)를 따른다. 카탈로그 2.3.0에서는 변경 상태 확인 경로 50개와 직접 진행 안내 39개를 연결했다. 읽기 전용 21개는 별도다. 실기기 검증은 미완료다.
