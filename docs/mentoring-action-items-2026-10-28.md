자동 실행할 수 없는 버튼은 기존 수동 안내를 유지한다. ON으로 변경하면 다음 안내부터 적용된다.

## 남은 작업 우선순위
1. 뒤로가기·홈·다른 창 이동 후 원래 목표를 유지하며 재탐색/복구.
2. fallback 에이전트를 제거하고 단일 판단 에이전트 아래 화면·OCR·API 도구 통합.
3. 명확한 상태 전이와 검증은 일반 코드로 처리, 모호한 판단만 에이전트에 위임.
4. 사용자 컨텍스트 생성·저장 및 수정/삭제 흐름 설계.
5. 다른 창 재탐색, 스크롤 탐색 및 긴 캡처 실기기 검증.
6. 검색/분석/STT 처리 상태 표시 및 온디바이스 지연 측정.
7. Bedrock 데이터 경로·보존 정책과 민감정보 음성 처리 경로 검증.
8. 도구 선택·파라미터·순서를 평가하는 100개 이상 시나리오 작성. STT 속도·정확도·비용 측정.

멘토링에 등장한 모델/서비스 이름과 가격, DDR 의미는 확정된 요구사항으로 간주하지 않고 확인 후 결정한다.

## 슬라이더 자동 조절 범위
자동 터치 ON이면 확인 단계를 거친 글자 크기 증가/감소 안내에서 설정 앱의 SeekBar를 한 단계 조절한다. 에이전트의 명시적 font_size 정책과 방향이 필요하다. 현재 값/범위/화면/창/위치를 실행 직전에 검증하고, 실제 값이 바뀐 경우에만 조절 이벤트를 전달한다. 최종 성공 여부는 기존 관측 기반 검증을 따른다. 동일 안내를 반복 자동 실행하지 않으며, 지원하지 않는 접근성 동작은 수동 안내를 유지한다. 임의 앱 슬라이더와 앱 찾기 전체 자동화는 이번 변경에 포함되지 않는다.
