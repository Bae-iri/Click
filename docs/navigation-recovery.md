# 잘못 이동한 화면에서 작업으로 복귀하기

## 한 번의 뒤로가기 판단

LLM 추측 대신 이번 작업에서 관측한 기록을 사용한다. 다음 조건을 모두 만족하면 뒤로가기를 한 번 제안한다.

- 실제 안내 대상을 찾았던 직전 화면이 있다.
- 그 화면에서 안내 대상과 다른 항목을 누른 이벤트가 정확히 한 번 관측됐다.
- 현재 화면은 직전 화면과 다르고 같은 앱에 있다.
- 이번 이탈에서 아직 뒤로가기를 시도하지 않았다.

이는 Android의 실제 백스택을 읽는 보장이 아니라 보수적인 휴리스틱이다. 한 번 돌아간 뒤에는 현재 화면을 다시 관측한다. 이전에 확인한 화면으로 돌아온 근거가 있으면 현재 상태에서 안내를 이어간다. 다른 앱, 여러 번 조작, 기록 부족, 복구 실패라면 홈으로 이동하도록 안내한다. 뒤로가기 후 화면 변화가 없으면 2.5초 뒤 홈 안내로 전환하며 자동으로 반복해서 뒤로가기를 실행하지 않는다.

시스템의 실제 뒤로가기·홈 컨트롤이 접근성 창에 노출되면 관측한 사각형을 하이라이트한다. 버튼이 없는 제스처 모드, 접근성 트리에 시스템 컨트롤이 없는 기기에는 안내 창 안의 동일 동작 버튼을 붉은 테두리로 강조한다. 버튼 좌표는 추측하지 않는다. 강조된 대체 버튼은 사용자가 누를 때만 Android의 전역 뒤로가기·홈 동작을 실행한다.

실제 내비게이션 버튼 클릭과 이전에 관측한 화면으로 복귀한 정황을 함께 본다. 접근성 이벤트가 누락되거나 제스처 결과를 기존 화면과 연결할 수 없으면 한 번의 뒤로가기를 보장하지 않고 홈 복귀를 안내한다. 제조사별 실기기 검증은 필요하다.

## 홈 이후

`home_navigated` 이벤트와 실제 런처 노드가 함께 들어오면 기존 목표·세션·에피소드는 유지한다. 이전 경로, 진행 체크, 조작 대기, 확인 대기, 비전 승인, 실패 제외 목록과 복구 횟수는 초기화한다. 홈에서 앱을 찾는 첫 경로부터 다시 안내한다. 홈 버튼을 눌렀다는 주장만 있고 런처 관측이 없으면 경로를 초기화하지 않는다. 중복 이벤트나 다른 세션의 이벤트도 재적용하지 않는다.

뒤로가기는 현재 조작 시도와 확인 대기를 중단하고 실제 돌아온 화면을 재분류한다. 목표를 다시 요청하거나 task graph를 바꾸지 않는다.

## Agent 2와 시간 기록

- 아무 버튼이나 누른 시간을 기록하던 연결을 제거하고, 안내 대상에 일치한 실제 수동 탭만 기록한다.
- 잘못 누름·복구·앱 이탈 시 현재 시간 측정을 폐기한다. 새 안내가 표시되면 새 구간을 시작한다.
- 자동 조작은 사람의 응답 시간으로 기록하지 않는다.
- 홈·뒤로가기 맥락은 동의가 있는 경우 `navigation_recovery`로 기록한다. 이해도 점수·증거 수·화면 난이도에 반영하지 않는다.
- 실행 기록에도 `user_home_navigation`/`user_back_navigation` 이유와 `count_attempt=false`를 남긴다. Agent 2의 오프라인 레이블은 `navigation_recovery`이며 성공·실패 학습 사례로 쓰지 않는다.

## 자동화 설정

Click 메뉴의 **지원 작업 전체 자동화** 스위치로 기기 로컬 설정을 저장한다. 기본 OFF다.

- ON: 현재 지원하는 설정 앱 찾기, 앱 열기, 설정 메뉴 이동, 자동 스크롤, 글자 크기 변경 확인과 슬라이더 조절.
- OFF: 위의 자율 실행을 끄고 위치·방향을 안내한다. 사용자가 명시적으로 누르는 복구/스크롤 버튼은 사용할 수 있다.
- 복구의 홈·뒤로가기는 ON이어도 사용자가 선택한다. 결제·전화·메시지·임의 앱 실행은 자동화 범위에 포함하지 않는다.

지원하는 task graph의 자동화 범위를 뜻하며 모든 앱의 모든 작업을 지원한다는 의미는 아니다. 자동 조작 전에는 기존 화면·창·대상 검증과 중복/횟수 제한을 계속 적용한다.

앱과 Backend를 함께 반영해야 새 `home_navigated` 이벤트와 복구 맥락을 처리할 수 있다.

검증: Android 전체 단위 테스트 209개와 디버그 APK 빌드 통과. AI-Agent 전체 테스트 212개 통과. Backend 전체 회귀 테스트 1,014개 통과 후 홈 이동 API·개인화 테스트 7개도 확인했다. 한 번의 뒤로가기 제안/실패 전환, 중복 클릭 방지, OFF 상태의 자율 동작 차단, 경로 초기화·목표 보존, Agent 2 중립 기록을 포함한다. 실기기 검증은 남아 있다.

자동 클릭·슬라이더의 실제 실행 경로 보완은 [후속 수정 문서](automation-touch-fixes-2026-10-30.md)를 따른다.
