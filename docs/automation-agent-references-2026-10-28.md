그록봇의 전화 발신 기능과 구체적인 확인 UX는 여기서 확인한 공식 자료만으로 확정하지 않았다. 전화 기능은 구현하지 않았다. 제품의 홍보 성능 수치·내부 구조도 Click 설계의 전제로 사용하지 않았다.

## 이번 변경의 구체적 동작

1. 설정의 버튼 자동 터치 ON에서만 지원 버튼/글자 크기 슬라이더 실행.
2. 안내 대상으로 지목된 글자가 클릭 불가능하면 최대 두 단계의 부모 접근성 행을 검사. 설정 앱·같은 창·유효 위치·작은 행 크기를 만족하고 다른 컨트롤/민감정보/상충 문구가 없는 경우만 실행.
3. 실제 클릭 행의 문구·리소스·클래스·위치를 실행 직전 재검증. 좌표 터치로 우회하지 않음.
4. 자동 조작은 한 번에 하나. 새 화면 관측 전에는 다음 자동 조작을 시작하지 않음.
5. 같은 세션·에피소드의 같은 명령은 재실행하지 않음. 에피소드당 시도는 최대 24개이며 실패도 횟수에 포함.
6. 실행 후 350ms에 실제 화면/슬라이더 값 변화를 확인한 경우만 원래 안내 대상으로 동작 이벤트를 연결. 이벤트 시간은 검증 시점이 아닌 실제 실행 시점으로 기록.
7. 1.8초·5.5초 후에도 관측을 확인. 변화 미확인 시 반복 클릭 없이 직접 조작 안내. 실제 서버 성공 판정은 기존 대상/방향/상태 검증에 따름.
8. 취소·서비스 종료로 실행 세대가 바뀌면 대기 중 확인 작업을 무효화하고 로컬 실행 기록 초기화. 새 에피소드/세션에는 별도 횟수 적용.

관측된 변화는 성공 판정과 다르다. 알림 등 다른 변화가 있어도 서버의 작업 전이 검증을 통과해야 성공한다. 지원하지 않는 슬라이더, OCR에서 얻은 좌표, 토글, 위험 동작에는 자동 실행을 확대하지 않았다.
