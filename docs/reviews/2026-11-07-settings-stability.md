# 공통 설정 작업 안정화 — 2026-11-07

## 변경 범위

- 글자 크기 전용 Jev 제한을 승인된 모든 슬라이더 작업에 적용한다. 그래프의 설정 식별 근거가 없는 컨트롤은 모델 후보로 보내지 않는다. 같은 식별 근거를 가진 컨트롤이 중복되면 보류한다.
- 미디어 음량은 벨소리·알림·시스템과 구분되는 이름 또는 실제 작은 접근성 행의 라벨과 단일 슬라이더로 식별한다. 페이지 전체의 ‘음량’ 제목은 채널 식별 근거가 아니다. 재사용·결과 확인·Android 승인·조작 직전에도 대상 검증을 적용한다.
- 음량 그래프 1.0.1은 시스템 채널을 제외한다. 기존 1.0.0과 DB에서 동률이 되지 않도록 우선순위를 올린다. 그래프 검증은 조작 방향과 확인 술어 불일치, 이름 없는 미디어 채널 허용을 거부한다.
- `COMPLETED`/`done`만으로 큐를 성공 종료하지 않는다. 변경 확인 또는 사용자의 결과 응답 근거가 없는 완료 명령은 안내를 중단하고 확인 불가로 표시한다.
- 확인 불가 문구를 UI와 음성에서 제거하지 않는다. 기술적 변경 확인과 사용자 보고 종료를 구분한다. 결과 프롬프트에는 technical_status를 함께 전달한다.
- 같은 안내·결과 프롬프트 재수신은 창을 다시 열거나 재낭독하지 않는다. 새 guide ID나 관련 없는 화면 변화로 같은 조작을 반복할 수 없다. 중단·재시도는 사용한 조작 한도를 환불하지 않는다.
- 판단 복구 한도는 노드 배치가 바뀌어도 같은 그래프 단계에서 유지한다. 한도 뒤에는 사용자 재시도·명시적 뒤로/홈 동작을 기다린다.
- Samsung의 큰 정수 밝기 범위는 유효한 작은 비율 단위로 이동한다. 수천만 범위에서 정수 한 칸만 움직여 실제 설정이 바뀌지 않는 경우를 방지한다.

## 검증 범위와 한계

`Backend/tests/test_settings_stability_matrix.py`는 설정 홈부터 글자 크기·밝기·미디어 음량의 증가/감소를 각각 실행한다. 정상 변경, 무조작, 다른 슬라이더, 뒤로 가기, 창 재생성, 오래된 관측, 저장 후 복원 42개 조합과 배치 변화에 대한 복구 한도 6개를 검사한다. 추가로 인증된 API에서 6개 작업 각각의 일시정지·재개·취소 후 관측 거부를 검사한다. 모델 응답은 통제된 테스트 응답이며 실제 Jev 정확도 측정 결과가 아니다.

Android 검사는 대상 식별, 잘못된 채널 거부, 실제 서비스의 중복 결과 표시·음성 방지, 사용자 보고 종료의 문구, 조작 한도 보존을 포함한다.

실제 기기 검증기는 `LiveNativeSettingsStabilityTest`다. 매 작업을 Android 설정 홈에서 시작하고 실제 Jev에 요청한다. 변경 동의 전 반복 관측에서 실제 값이 유지되는지 확인하고, 실제 조작·시스템 값 변경·서버 CHANGED 및 결과 질문 도달을 모두 요구한다. 만족 응답을 대신 제출하지 않는다. 테스트 세션을 취소하고 글자 배율·밝기·자동 밝기 모드·미디어 음량·접근성 및 자동 조작 설정을 복원한다. 다른 음량 채널이 바뀌면 실패한다.

실제 기기의 모든 부정 시나리오가 통과한 것으로 해석해서는 안 된다. 위 54개 조합은 재현 검사이며, 물리 기기 검증기는 별도 실행 근거가 있어야 통과로 기록한다.

## 배포 및 실기기 실행

Backend와 AI-Agent를 함께 배포하고 업데이트 앱/검사 APK를 빌드한다. 실제 서버와 APK가 같은 목적지를 호출해야 한다. 다음 명령은 로컬 Backend/AI 소스 SHA256와 서버 `/version`을 대조한다. 다르면 화면 요청과 기기 조작을 시작하지 않는다.

```sh
cd Backend
python3 scripts/native_settings_check.py --base-url https://click-db.onrender.com
python3 scripts/native_settings_check.py --base-url https://click-db.onrender.com --run-live --apk-dir ../Frontend/app/build/outputs/apk --report /private/tmp/click-native-settings-stability.json
```

앱 로그인과 기기 잠금 해제가 필요하다. APK 갱신은 기존 앱 데이터를 지우지 않는다. 버전 확인 실패·기기 검사 실패를 통과로 처리하지 않는다. 검증 결과에는 배포 소스 해시와 각 작업의 상태·기술 결과·실제 설정 전후 값·복원 값을 남긴다. 원본 화면이나 인증 정보를 보고서에 저장하지 않는다.

## 이번 실행 상태

2026-11-07 실제 서버의 공통 수정 소스 일치와 Jev 제공자 연결을 확인했다. 기기 검사 첫 실행은 첫 작업의 서버 응답 전 `AUTH_REQUIRED`로 종료했다. 실제 Jev 판단과 설정 변경은 수행되지 않았고 글자 배율 1.1·밝기 153·미디어 음량 6으로 복원을 확인했다. 여섯 작업의 실제 완료와 실기기 부정 시나리오는 통과 기록이 없다. 검사기는 이제 인증을 설정 조작보다 먼저 확인하며 고정 오류 코드만 보고서에 남긴다.

직접 CI 상태 조회는 기존 Git 인증정보의 별도 API 재사용을 자동 승인 검토가 거부해 수행하지 않았다. 로컬 전체 검사와 공개 서버 배포 소스 확인 결과는 CI 성공 확인과 구분한다.
