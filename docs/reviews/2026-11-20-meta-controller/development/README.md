# 개발 자료 — 최종 성능 집계에서 제외

- `smoke-v1-*`: 짧은 명사 요청을 사용한 2회 연결 점검. 시작 화면의 메뉴 항목을 완료 조건으로 잡는 문제와, 시험 조작자가 결과를 자동 확인하던 계측 문제를 발견했다. 이후 요청을 명시적인 화면 열기/탭 이동 문장으로 바꾸고 자동 결과 확인을 제거했다.
- `probe-v1.json`: 원문 화면을 저장하지 않은 공개 컨트롤 점검. Chrome 시작 화면에도 '새 탭'이 있어 Chrome 메뉴의 정답을 메뉴에만 있는 '새 시크릿 탭'의 **표시**로 교정했다. 해당 항목을 실행하지 않는다.
- `interrupted-v2-*`: 63회 뒤 중단한 실행. 27회의 시계 준비 실패가 '이미 선택된 알람 탭은 클릭 불가'라는 초기화 코드 오류에서 발생했다. 이 오류를 제품이나 MC의 실패로 해석하지 않는다. 후보 정책은 유지하고 시작 탭이 이미 선택됐으면 유효한 초기 상태로 인정하도록 수정한 뒤, 새 v3 실행에서 전체 216회를 다시 예약했다.
- `v2-to-v3-instrumentation.patch`: 위 초기화 수정과 모델 호출 없는 전체 시작 상태 점검 추가. MC 정책/모델 프롬프트/목표 정답은 변경하지 않았다.
- `interrupted-v3-*`: 47회 뒤 중단한 개발 실행. 15회에서 단발 네이티브 관찰이 시작 상태를 다시 읽지 못했다. 물리적으로 다른 앱이 열렸다는 근거와 구분한다. 시험 조작자가 TAP만 허용해 기존 back/scroll/선택한 앱 열기를 막고 있던 제한도 수정했다. v4에서는 같은 공개 앱·창의 관찰 3회 이상과 600ms 이상을 요구하는 준비 경로를 preflight와 실제 실행에서 공유한다.
- `v3-to-v4-instrumentation.patch`: 위 초기화·공통 탐색 도구 수정, 독립 oracle 관측 불가와 목표 부재의 분리, 키보드/실험 overlay 창 선택, 요청 간 모델 작업 대기 분리. TAP은 별도의 탐색 허용 목록으로 제한해 초기화·타이머 시작·설정 조절 등은 실행하지 않는다. 후보 MC 정책·모델 프롬프트·12개 요청·목표 의미 조건은 바꾸지 않았다.

이 자료는 개발·중단 이력의 투명성을 위해 보존한다. 최종 v4 에피소드와 합치거나 전체 252회 제품 실험을 수행한 근거로 사용하지 않는다. 초기 oracle은 관측 불가를 목표 부재와 혼동할 수 있었으므로 이 자료의 잘못된 VERIFIED 제시 수를 최종 안전성 근거로 쓰지 않는다. 중단된 실행의 마지막 모델 호출 로그는 완결 수집이 아닐 수 있다.
