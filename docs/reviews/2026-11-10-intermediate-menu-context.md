# 중간 설정 메뉴의 Jev 판단 문맥

SM_N981N의 VPN 연결 요청이 연결 화면에서 멈췄다. 기기에서 기타 연결 설정 행이 보였고,
설치 앱과 운영 서버의 공유 계약 해시는 일치했다. 실제 로그에서는 후보 1개가 정확히
잡혔지만 Jev 신뢰도가 0.35~0.53으로 0.8 기준에 못 미쳐 반복 보류됐다.

모든 승인 메뉴 이동 후보에 현재 페이지·바로 열 페이지·남은 메뉴 경로를 추가한다.
연결 → 기타 연결 설정 → VPN처럼 바로 다음 메뉴와 최종 목표가 다름을 명확히 전달한다.
경로 설명은 허용 어휘에 있는 승인 그래프 제목만 사용하며 변경 확인·값 조작·수동 진행
경계를 넘지 않는다. 모델의 보류를 규칙 선택으로 대체하거나 신뢰도 기준을 낮추지 않는다.

관련 경로·Jev·확인/보류 검사 187개, 개인정보·관찰·진단 검사 106개를 통과했다.
그래프·카탈로그·공유 계약·앱 코드는 바뀌지 않아 서버 배포만 필요하다.
실제 Jev와 휴대폰에서의 최종 진행 확인은 서버 반영 후 수행한다.
