# 민감 설정에서도 작업 목적과 다음 단계 안내

직접 진행 설정 33개는 시작 안내·설정 화면 도착·개인정보 입력 보호·결과 질문에서
요청한 작업을 명시한다. 예: “VPN 설정 화면으로 안내할게요” 이후 사용할 프로필과
인증 정보 입력 방법을 안내한다. 연결과 연결 해제, Wi-Fi 연결과 공유의 설명을 나눴다.
이 문구는 모델이 만들어 내지 않고 앱과 서버가 같은 승인 문구 파일을 읽는다.

민감 입력을 만난 승인 수동 설정은 실패 그림 대신 “설정을 직접 이어가 주세요” 화면을
보여준다. 사용자는 안내를 읽고 창을 접어 기기에서 직접 진행하거나 안내를 끝낼 수 있다.
화면 전송·자동 조작은 멈춘 상태이며 재개나 성공을 자동으로 기록하지 않는다.
검증되지 않은 결과는 사용자 보고로만 처리한다. 알 수 없는 목표·앱·화면 오류의 의미와
기존 개인정보 차단은 유지한다. 저장된 graph와 승인 조건은 바꾸지 않는다.

메뉴 선택 질문도 실제 독립 제목이 맞고 후보가 단일한 읽기 전용 메뉴일 때만
현재 수행할 한 단계에 초점을 맞춘다. 전체 요청 목표는 그대로 전달하며 모델 보류나
신뢰도 기준을 우회하지 않는다.

Backend·AI-Agent 회귀 822개, 메뉴/개인정보 회귀 63개, Android 전체 643개 검사를 통과했다.
실기기 VPN 화면 도달은 관찰했으나 연결 화면의 중간 메뉴에서 낮은 신뢰도가 남은 기록도
있으므로 모든 자동 이동을 검증했다고 주장하지 않는다. 이번 문구와 화면은 앱 업데이트가
필요하며 서버의 시작·결과 안내는 서버 업데이트가 필요하다.

새 APK는 빌드했으며 ADB 연결이 끊겨 기기 설치는 완료하지 않았다.
