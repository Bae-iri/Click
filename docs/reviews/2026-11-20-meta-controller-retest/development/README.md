# 사전 준비 실행 기록

주 비교는 최종 고정한 `controlled-v3`와 `live-v1`만 사용한다. 아래 준비 실행은 주 비교에 합치지 않는다. 이전 Galaxy Note20의 216회 실험도 별개의 역사적 결과다.

- `controlled-v1`: 72회. 시험 화면의 검색 필드·대기 표제·실행 재관찰과 실제 구현의 정합성을 검토하기 위한 준비 실행이다.
- `controlled-v2`: 72회. 모델이 제안할 수 있는 `back`/`open_app`을 지원하지 않는 경우 안전 위반으로 잘못 세는 평가기 문제를 독립 검토에서 발견했다. 최종 실행 전 도구 의미와 별도 `unsupported_tools` 계수를 고정했다. 유료 모델 호출은 시작하지 않은 상태였다.
- `native-test.log`: 첫 Android 회귀 검사는 Activity 전환 애니메이션 도중 화면이 달라져 실행 정책이 거절했다. 이 기록을 같은 물리 화면의 실패로 해석하지 않는다. 시험 화면 안정화 대기와 실행 직전 동일 관찰 검사를 추가했다.
- `native-test-v2.log`: 준비 조건 보완 후 실제 Android 회귀 검사 1개 통과. 최종 소스 APK의 별도 재검사도 통과했으며 루트의 `native-verification.log`에 보존한다.
- 최초 JVM 컴파일에서는 Android의 컴파일 API에 없는 `Files.writeString`을 사용했다. 호환되는 바이트 쓰기로 수정한 뒤 검사와 실험을 진행했다. 이 컴파일 실패에서 생성된 실험 에피소드는 없다.

준비 단계의 소스 해시는 `preflight-context.json`에, 주 비교의 소스 해시는 상위 `measurement-context.json`에 있다. 준비 실행 결과를 보고 MC-v0 정책, 주 비교의 작업 선택, 목표 정답 또는 모델 응답을 조정하지 않았다. 준비 단계에서는 시험 장치와 집계의 오류만 수정했다.
