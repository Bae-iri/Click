# 기존 설정 89개 경로 확장

기존 89개 목표와 별도 설정 화면 열기 21개를 유지한다. 카탈로그 2.3.2에서
화면 요소 크게·작게를 확인 → 네이티브 슬라이더 조작 안내 → 실제 화면 배율 검증으로
확장했다. 변경 상태 검증 경로는 56개, 사용자 직접 진행 안내는 33개다.

나머지 11개 목표에는 공공 메뉴의 중간 경로와 정확한 안내 종료 화면을 보완했다.
VPN 연결·해제, 프라이빗 DNS, 저장된 Wi-Fi, 핫스팟 비밀번호, 언어, 키보드,
화면 잠금 방식, 앱 알림 켜기·끄기, 알림 기록이다. 저장된 Wi-Fi는 Wi-Fi → 고급 설정 →
네트워크 관리로 이동하며 중간 메뉴가 없는 기기의 직접 진입도 지원한다.
알림 기록은 고급 설정에서 직접 진행으로 넘기고, 내용 화면 차단은 유지한다.
비밀번호·기기 이름·네트워크 이름과 같은 임의의 문자열은 허용 어휘에 추가하지 않는다.

공통 화면 분류기는 독립적인 제목의 완전 일치를 부분 일치보다 우선한다. 따라서
기타 연결 설정을 설정 홈으로, 언어 및 입력을 언어 화면으로 오인하지 않는다.
실제 RangeInfo가 있는 네이티브 슬라이더 내부의 값 없는 가상 눈금만 중복 후보에서 제외한다.
삼성 화면 확대의 눈금 5개가 실제 슬라이더와 경쟁하지 않도록 하며, 화면 크기 작업은 실제
수치가 있는 조절 대상으로 한정한다.

화면 크기는 기본 디스플레이에서 읽은 Configuration.densityDpi의 유효한 정수와
원래 네이티브 대상의 이동 방향이 함께 바뀌어야 성공이다. 새 관찰·원래 조작 이벤트·
확인 응답이 필요하며, 화면 재생성도 같은 리소스와 대상 키가 유지되는 경우만 허용한다.
Android는 배율 수치를 화면 크기 작업에만 내보내며 값·출처 짝을 검증한다.
Python과 Android는 동일한 성공 증거 fixture를 실행한다.

13개 변경 목표만 새 graph 1.1.0으로 발행한다. 나머지 승인 graph의 내용 해시는 그대로이며,
기존 1.0.0에 고정된 실행을 보존한다. 새 목표나 다른 앱 작업을 추가하지 않았다.

Backend 전체 2,248개와 Android 전체 559개 검사가 통과했다. 성공 값 범위를 추가한 뒤
관련 Android 계약 72개도 통과했다. 공통 슬라이더 정규화의 마지막 변경 후에도 관련
Backend·AI-Agent 991개 회귀를 추가로 통과했다. 마이그레이션·인증/턴·프로세스 재시작과
재개/취소 smoke 검사도 통과했다.

SM_N981N에서 공개 화면 확대 페이지의 네이티브 슬라이더와 배율 값을 읽는 검사 1개를
통과했다. 필터링된 실제 관찰을 서버 HTTP 경로에 넣으면 확대·축소 모두 눈금이 아닌
실제 슬라이더 하나를 지정해 확인 대기한다. 실기기의 화면 크기는 바꾸지 않았으며
실제 변경 후 효과는 합성 네이티브 관찰 회귀로 검증했다. 실제 Jev API 평가를 의미하지 않는다.
APK를 연결된 기기에 설치하고 설치 파일 해시 및 원래 접근성 설정 복원을 확인했다.

서버와 앱이 함께 업데이트되어야 새 경로가 동작한다. develop 자동 배포는 GitHub Actions
계정 결제·사용 한도 문제로 대기 중이며, 배포 완료로 보고하지 않는다.
