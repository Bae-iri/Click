# 사용자가 결과를 확인할 수 있는 화면까지의 실험

**설계만 작성했으며 아직 실행하지 않았다.** 성공은 CLICK이 완료를 선언하는 순간이 아니라, 요청한 목표 상태가 실제로 충족되고 사용자가 그 결과를 화면에서 확인할 수 있는 순간으로 정의했다.

- 주 실험: 정상 제품 경로, **37과제 × 표현 2개 × 시작 상태 2개 = 148회**.
- 주 지표: **목표 결과 화면 제시율**, **요청 → 첫 유효 안내 시간**, **요청 → 결과 확인 가능 시간**.
- 종료 조건: 독립 기기 판정 + 가려지지 않은 화면 근거 + 1초 유지. 완료 검증·‘네, 됐어요’·서버 `COMPLETED`를 기다리지 않는다.
- 기존 ‘도착’ 기록을 새 성공으로 재분류하지 않는다. 기기 1대·스크립트 승인 조건을 명시한다.
