## 측정 도구 주의 (Windows 빌드)

Windows 작업 폴더는 `AI-Agent/goal_catalog/*.json`을 CRLF로 체크아웃한다. 앱은 이 파일들의 바이트 해시를 계약으로 내장하고 운영(Linux)은 LF 해시를 쓰므로, Windows에서 빌드한 APK는 운영과 `capability_contract`가 달라 자동 탭을 거부하고(`capability_incompatible`) 앱 과제는 즉시 오류로 끝난다. 이번 측정은 해당 JSON을 LF로 맞춰 빌드했다. `before-app-fix/`는 그 전에 develop `32636ab7` 앱으로 운영(`32636ab7`)을 측정하다 중단한 10건이다. 9건이 탭 안내 뒤 자동 탭 없이 시간 초과였으며, 이 APK도 Windows(CRLF) 빌드라 계약 불일치와 가림 버그 중 어느 쪽인지 구분하지 못했다. 성능 수치로 쓰지 않는다.
