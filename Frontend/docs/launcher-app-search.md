# 앱 선택과 런처에서 앱 찾기

일반 앱 작업은 기기에 설치된 실행 항목을 기준으로 대상 앱을 선택한다. “연락처 앱에서”처럼 사용자가 지정한 앱을 우선한다. “전화번호 키패드에 즐겨찾기”나 “단축번호 등록”은 Android 기본 전화 앱의 번호 없는 `ACTION_DIAL`로 연결한다. 전화번호 입력이나 발신은 이 동작에 포함되지 않는다.

자동 조작이 켜져 있으면 설치된 앱을 직접 열고 실제 전면 창을 확인한다. 키패드 요청은 전화 앱 안에서도 키패드가 보이는지 확인한다. 진입 뒤에는 같은 앱의 다음 메뉴로 이동할 수 있다. 작업 도중 다른 앱으로 넘어가면 원래 작업에서 선택한 앱으로 한 번 복귀한다. 반복 이탈은 기존 열기 버튼으로 사용자가 결정한다. 수동 모드에서는 기존 열기 버튼이나 화면에 보이는 앱 아이콘을 사용한다.

직접 실행할 수 없고 런처를 관찰할 수 있을 때의 대체 탐색은 다음과 같다.

1. 현재 창에 하나만 보이는 대상 앱 아이콘을 확인한다.
2. 홈과 앱 서랍의 각 페이지를 확인한다. 폴더는 자식 아이콘에 대상 앱 이름이 표시되고 일치하는 폴더가 하나일 때만 연다. 폴더 제목만으로 소속 앱을 판단하지 않는다.
3. 매 동작 직전에 전면 창과 대상을 다시 확인한다. 폴더 미리보기와 열린 폴더 뒤에 있는 배경 아이콘은 누르지 않는다.
4. 이미 열려 있던 폴더에서 앱이 보이지 않으면 뒤로 나온다. 확인된 미리보기와 실제 내용이 다르면 해당 폴더의 탐색을 마치고 다른 페이지로 이동한다.
5. 조작 결과가 확인되지 않거나 탐색 한도(최대 40회 동작, 활성 시간 45초)에 도달하면 직접 열기 안내로 전환한다.
