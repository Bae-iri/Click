# Click 온보딩 UI 모듈

현재 이 모듈은 독립 프리뷰 앱이 아닌 `com.android.library`다. `:app`이 새 화면과 실제 인증·접근성·오버레이를 함께 포함하며 설치 이름은 **Click**, 패키지는 **com.click**이다.

Android Studio에서는 **Click / app** 실행 구성을 사용한다. 빌드는 `:app:assembleDebug`, 테스트는 `:app:testDebugUnitTest :design-preview:testDebugUnitTest`로 실행한다. 별도 `com.click.designpreview` APK를 설치하지 않는다.

온보딩은 3페이지이며 마지막에 회원가입/로그인을 선택한다. 가입은 8자 비밀번호, 이메일 재확인, 선택형 직업 입력과 실제 서버 가입을 연결한다. 접근성 미루기는 `AccessibilityHelpActivity`로, 허용 후에는 같은 앱의 준비 화면으로 연결된다. 연동은 `ClickHost`와 앱의 `ClickApplication`이 담당한다.

상세 계약·검증·운영 서버 배포 차이는 [변경 기록](../../docs/goal-progress-result-flow.md)을 참고한다.

# Click 디자인 프리뷰

새 FE 디자인을 넣고 실행할 수 있는 독립 Android 앱 모듈이다. 현재는 제공된
참고 이미지를 기준으로 Click 스플래시와 웰컴·온보딩 4개 화면을 구현했다.

밝은 배경, 파란 커서와 둥근 `click` 워드마크, 소개 문구, 하단 곡선과 손글씨로
구성한다. 중앙 로고와 하단 `click` 글자는 제공된 PNG 이미지를, 곡선은 벡터를 사용하며,
상태 표시줄·내비게이션 영역과 화면 크기에 맞춰
배치한다. 첫 실행에는 짧은 등장 효과 뒤 중앙 로고가 살짝 커졌다 눌리고 원래 크기로
돌아오는 클릭 효과를 한 번 재생한다. 시스템에서 애니메이션을 끄면 두 효과 모두 생략한다.
스플래시는 앱이 화면에 표시된 시간 기준으로 2초 후 온보딩 1페이지로 이동한다.
백그라운드에서는 타이머를 멈추며, 화면 회전 시 남은 시간을 복원한다.
전환 후 스플래시는 종료되어 뒤로 가기로 돌아오지 않는다.

## 웰컴과 온보딩

흰 배경과 블루 톤으로 다음 4개 화면을 구성한다. `welcome.png` 원본과 기존
Click 커서 벡터를 사용하며, 휴대폰 일러스트·말풍선·체크 목록·그라데이션 버튼은
네이티브 UI로 구현했다. 문구는 이미지에 포함하지 않아 시스템 글자 확대를 지원한다.

1. `처음이신가요?`: 할머니 일러스트와 시작하기, 건너뛰기.
2. `궁금한 화면을 물어보세요`: 휴대폰과 흰색 질문 말풍선.
3. `원하는 것을 대신 찾아드려요`: 요청 예시와 파란색 답변 말풍선.
4. `이제, 더 편하게 사용해보세요!`: Click 배지와 기능 체크 목록.

- 제목·설명·말풍선은 시스템 글자 크기 설정을 따른다.
- 글자 확대 또는 좁은 화면에서는 말풍선을 일러스트 위로 옮겨 겹침을 줄인다.
- 작은 화면에서는 본문이 스크롤되며 시작하기 버튼은 하단 안전 영역 위에 유지된다.
- 웰컴 문구는 시안처럼 좌우 여백을 두고 왼쪽 정렬하며, 이후 제목은 중앙 정렬한다.
- 웰컴 캐릭터는 본문 너비의 90%, 최대 320dp로 표시한다.
- 건너뛰기는 최소 48dp, 시작하기는 최소 66dp 터치 높이를 확보한다.
- 웰컴의 시작하기와 중간 화면의 다음이 실제 페이지를 전환한다.
- 웰컴을 제외한 모든 화면에 왼쪽 위 `이전` 버튼을 제공하며, 마지막 화면에서도 이전 단계로 돌아갈 수 있다.
- 건너뛰기는 마지막 안내 화면으로 이동한다. 시스템 뒤로 가기는 이전 페이지로 이동한다.
- 상단 3단계 진행 표시는 현재 소개 단계에 맞춰 바뀌며, 화면 회전 시 페이지를 복원한다.
- 다음 버튼은 첫 화면의 시작하기와 동일한 너비·높이·그라데이션으로 하단에 배치한다.
- 마지막 화면의 체크는 화면이 보인 뒤 잠시 기다렸다가 위에서 아래로 하나씩 원이 채워지고 체크 선이 그려진다.
  전체 재생 시간은 약 2.3초다.
- 작은 화면에서는 체크 목록이 보일 때 재생한다. 화면 재진입·복원·회전·백그라운드 복귀 시에도 다시 재생한다.
  시스템 애니메이션 끄기 설정에서는 완료된 체크 상태를 즉시 표시한다.
- 에뮬레이터에서 체크가 즉시 완료되면 개발자 옵션의 `Animator duration scale`을 확인한다.
  애니메이션 미리보기는 기본값 `1x`에서 검증한다.
- 마지막 시작하기는 회원가입 화면으로 이어진다.
- 마지막 화면의 `접근성 설정 안내`를 누르면 가입 입력 없이 권한 안내를 다시 볼 수 있다.
- 앱을 새로 실행하면 스플래시와 온보딩을 다시 보여준다.

## 회원가입

가입은 한 번에 많은 정보를 묻지 않도록 두 화면으로 나눴다. 첫 화면에서는 로그인에
필요한 이메일과 8글자 이상 비밀번호를, 다음 화면에서는 필수 나이와 선택 직업을
받는다. 성별은 기존 앱에서 서버 가입 정보가 아니라 기기 안 프로필 표시에만 쓰이고
있으므로 가입 단계에서는 제외했다.

- 각 입력칸은 64dp, 하단 버튼은 66dp 이상으로 두고, 라벨을 입력칸 위에 표시한다.
- 비밀번호는 보기·숨기기 버튼으로 입력을 확인할 수 있고, 오류는 해당 항목 바로 아래에
  큰 글자로 표시한다.
- 나이는 서버가 요구하는 연령대 값으로 변환하기 위한 정보이며, 생년월일을 받지 않는다.
- 직업은 `선택하지 않음`을 기본값으로 둔다. 실제 서버에서는 선택했을 때만
  `occupation_category`로 보낸다.
- 프리뷰는 입력 형식과 화면 전환만 검증한다. 개인정보를 저장하거나 실제 가입 API를
  호출하지 않는다.
- 나이 입력을 확인한 뒤 `다음`을 누르면 접근성 권한 안내로 이어진다.

## 접근성 권한 안내

참고 시안의 흰 배경·블루 버튼·큰 글씨·설정 화면 일러스트를 반영한 5단계 안내다.

1. Click 로고와 휴대폰을 누르는 일러스트로 앱의 역할을 소개한다.
2. 접근성 권한이 필요한 이유를 설명한다.
3. 버튼 찾기·글자 읽기·확인 안내·권한 선택을 카드로 소개한다.
4. 삼성 휴대폰의 설정 앱과 접근성 메뉴를 안내한다. 설정 아이콘은 실제 설정 앱을 연다.
5. 설치된 앱에서 click을 선택하고 켜는 방법을 안내한다. `지금 설정하기`는 실제 Android 접근성 설정을 연다.

이전·다음·나중에 설정하기를 지원하고 화면 회전 시 현재 단계를 복원한다.
본문은 스크롤되며 하단 버튼은 시스템 내비게이션 영역 위에 고정된다.
그림 속 설정 항목도 네이티브 텍스트를 사용해 시스템 글자 크기를 따른다.
프리뷰는 접근성 서비스를 등록하거나 권한을 자동으로 켜지 않는다. 시스템 설정에
`click` 항목을 표시하려면 기능 앱(`com.click`)이 설치되어 있어야 한다.
실제 기능 앱은 서버 연동을 사용하므로 화면 정보가 외부로 전송되지 않는다고 안내하지 않는다.

## 작업 영역

| 경로 | 용도 |
| --- | --- |
| `src/main/java/com/click/designpreview/` | 새 화면 코드. 진입점은 `DesignPreviewActivity.java` |
| `src/main/res/layout/` | 새 화면 레이아웃. 시작 파일은 `activity_design_preview.xml` |
| `src/main/res/drawable/` | 새 이미지·아이콘·도형 |
| `src/main/res/drawable-nodpi/` | 제공된 `logo.png`, `click.png`, `welcome.png` 원본 이미지 |
| `src/main/res/values/` | 새 색상·테마·문구 |
| `src/main/res/font/` | 스플래시 손글씨 Gaegu와 온보딩 Pretendard 폰트 |
| `src/main/assets/` | 새 디자인에서 사용할 정적 파일 |

새 디자인 코드는 이 모듈에서 작업한다. 기존 `../app/`의 Activity, UI, 이미지,
테마, 서비스, API 코드 및 테스트는 보존하며 이 모듈에서 참조하지 않는다.
기존 디자인을 확인하려면 `app` 모듈을 실행한다.

## 실행

Android Studio에서 `Frontend/`를 열고 Gradle Sync를 실행한다.
실행 구성의 모듈로 `design-preview`를 선택한다. 실행 구성이 자동 생성되지 않으면
Run → Edit Configurations → + → Android App에서 해당 모듈을 선택하고
Launch를 Default Activity로 설정한다.

`Frontend/`에서 다음 명령으로 새 디자인 APK를 빌드한다.

```bash
sh ./gradlew :design-preview:assembleDebug
```

APK 경로는 `design-preview/build/outputs/apk/debug/design-preview-debug.apk`다.
기존 앱은 `sh ./gradlew :app:assembleDebug`로 빌드한다. Windows에서는
`gradlew.bat :design-preview:assembleDebug` 또는 `gradlew.bat :app:assembleDebug`를 사용한다.

빌드는 JDK 17 또는 21을 사용한다. Android Studio에 포함된 JDK 25는 현재
Gradle 8.7과 호환되지 않으므로 Gradle JDK 설정에서 17 또는 21을 선택한다.
타이머 단위 테스트와 Android 정적 검사는 다음 명령으로 실행한다.

```bash
sh ./gradlew :design-preview:testDebugUnitTest :design-preview:lintDebug
```

## 앱과 데이터 구분

| 모듈 | applicationId | 역할 |
| --- | --- | --- |
| `app` | `com.click` | 기존 디자인과 실제 앱 기능 |
| `design-preview` | `com.click.designpreview` | 새 디자인 실험 |

두 앱은 함께 설치할 수 있다. 새 앱을 설치해도 기존 앱을 덮어쓰지 않으며,
기기 내 로그인 토큰·설정·온보딩 상태를 공유하지 않는다.
프리뷰에는 서버 호출, 인증, 접근성 서비스, 오버레이, 마이크 사용을 연결하지 않았다.
실제 기능 연결은 새 디자인의 화면 구조가 정해진 후 별도 작업으로 진행한다.

## 폰트 출처

손글씨는 [Google Fonts의 Gaegu](https://github.com/google/fonts/tree/main/ofl/gaegu)를
사용한다. 원본 폰트와 SIL Open Font License 1.1을 함께 포함하며, 라이선스는
`src/main/assets/licenses/Gaegu-OFL.txt`에 보관한다. 중앙 로고와 하단 `click` 글자는
제공된 `logo.png`와 `click.png`를 이 모듈에 복사해 사용한다.

온보딩은 [Pretendard v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist)
Medium·SemiBold·Bold 원본 글꼴을 사용한다. SIL Open Font License 1.1 원문은
`src/main/assets/licenses/Pretendard-OFL.txt`에 보관하며, 실행 중 글꼴 다운로드는 없다.
